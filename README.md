## Project Description

**DON'T PRESS** is a fun Malayalam trolling website built around one simple idea — a button that repeatedly tells you **not to press it**.

Every click makes the website more dramatic, funny, and ridiculous, with Malayalam reactions, fake personality analysis, awards, emergency alerts, and a final achievement for absolutely nothing.

## The Problem (that doesn't exist)

People have a serious problem: **they cannot resist pressing a button that says "DO NOT PRESS."**

We decided that this completely unnecessary problem needed a completely unnecessary solution. 😂

## The Solution (that nobody asked for)

We created a giant **DO NOT PRESS** button that gets increasingly annoyed the more you press it.

The website progressively trolls the user through:

* 👀 Curious reactions
* 😂 Malayalam trolling
* 🏆 Fake championships
* 📊 Fake personality analysis
* 🚨 Emergency alerts
* 👮 Fake police investigation
* 💀 Complete hopelessness
* 🏆 A completely useless final achievement

After 50 clicks, the user discovers the ultimate truth:

**Nothing happened.** 💀

## Technical Details

### Technologies/Components Used

For Software:

* **Languages:** HTML, CSS, JavaScript
* **Framework:** React
* **Build Tool:** Vite
* **Styling:** Tailwind CSS
* **Libraries:** Lucide React
* **Browser APIs:** MediaDevices API, Canvas API
* **Tools:** Lovable, VS Code, Git, GitHub, Vercel

For Hardware:

* No hardware required.

### Implementation

For Software:

The website uses a click counter to control the different trolling stages.

Each milestone introduces a new interaction or visual effect. The application also uses the browser camera to allow the user to capture a photo, which is then used throughout the experience for humorous effects.

The camera photo is handled locally in the browser and is not uploaded to a server.

### Installation

```bash
git clone https://github.com/mariyathomas2/deadcode-useless123.git
cd deadcode-useless123
npm install
```

### Run

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
